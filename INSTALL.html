📚 Library Management System - Installation Guide

System Requirements

  • PHP: 7.4 or higher
  • MySQL: 5.7 or higher (or MariaDB 10.2+)
  • Web Server: Apache 2.4+ or Nginx 1.10+
  • Browser: Modern browser with JavaScript enabled
  • Disk Space: Minimum 100MB

Installation Steps

Step 1: Download/Upload Files

Place the library management system files in your web server directory:

  • For Apache: /var/www/html/library-management/
  • For Nginx: /usr/share/nginx/html/library-management/
  • Or in your hosting's public_html directory

Step 2: Create Database

Using phpMyAdmin or MySQL command line:

CREATE DATABASE library_management;
USE library_management;

Then import the schema file: database/library_schema.sql

Step 3: Configure Database Connection

Edit config/config.php and update:

define('DB_HOST', 'localhost');
define('DB_USER', 'your_mysql_user');
define('DB_PASS', 'your_mysql_password');
define('DB_NAME', 'library_management');
Note: If using a remote database, replace 'localhost' with your database server IP or hostname.

Step 4: Set File Permissions

Make these directories writable:

chmod 755 logs/
chmod 755 assets/uploads/
chmod 755 includes/
Linux/Unix Only: Contact your hosting provider if you can't set permissions directly.

Step 5: Access Application

Open your browser and navigate to:

http://localhost/library-management/
or
http://your-domain.com/library-management/

Initial Setup

Create Admin Account

  1. Go to /register.php
  2. Fill in the registration form with your details
  3. Click "Register"
  4. Log in with your new account (this will be your admin account)

Configure System Settings

After logging in as admin:

  1. Go to Admin Dashboard
  2. Click on "Settings"
  3. Configure:
    • Fine rates (daily, damage, lost)
    • Borrowing limits
    • Loan duration
    • Reservation hold period
  4. Save changes

Add Librarian Accounts

  1. Go to Admin Dashboard → User Management
  2. Click "Add User"
  3. Fill in details for librarian
  4. Select role as "Librarian"
  5. Save

Data Import

Add Books to Catalog

  1. Log in as Admin or Librarian
  2. Go to Book Management
  3. Click "Add New Book"
  4. Fill in book details:
    • Title, ISBN, Publisher
    • Category, Author(s)
    • Year, Edition, Pages
    • Physical location (shelf, section)
    • Book value/price
  5. Save

Add Authors and Publishers

Before adding books, you can pre-populate authors and publishers:

  1. Admin Dashboard → Metadata Management
  2. Add Authors and Publishers
  3. Then reference them when adding books

Testing the System

Test User Accounts

  1. Create a test librarian account
  2. Create a test member/student account via registration
  3. Test borrowing/returning as member
  4. Test fine calculation
  5. Test reservations

Backup & Maintenance

Regular Backups

Backup your database regularly:

mysqldump -u user -p library_management > backup_$(date +%Y%m%d).sql

Or use phpMyAdmin's backup feature

Clear Logs

Periodically clear old log files to save disk space:

rm -f logs/error_*.log
rm -f logs/activity_*.log

Troubleshooting

Database Connection Error

  • Verify MySQL is running
  • Check credentials in config/config.php
  • Ensure database was created correctly
  • Check MySQL user has correct permissions

White Blank Page

  • Check logs/error.log for PHP errors
  • Enable PHP error reporting (temporary): 
    error_reporting(E_ALL);
ini_set('display_errors', 1);
  • Check file permissions

Login Issues

  • Clear browser cookies
  • Verify user exists in database
  • Check user status (active/suspended)
  • Verify password is correct

Permission Denied Errors

  • Check directory permissions: ls -la
  • Fix with: chmod 755 directory_name/
  • For files: chmod 644 file_name
  • Contact hosting provider if can't change permissions

Security Recommendations

Initial Security Setup

  1. Change default admin password immediately
  2. Review and change configuration settings
  3. Set strong database password
  4. Restrict access to admin panel by IP (if possible)
  5. Enable HTTPS/SSL certificate
  6. Keep PHP and MySQL updated
  7. Regular backups of database and files
  8. Monitor audit logs regularly

Default Login Credentials

Important: After installation, create your own admin account through registration. There are NO default credentials.

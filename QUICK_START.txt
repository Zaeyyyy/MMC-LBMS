## Key Classes & Methods

### User Class
```php
register()              // User registration
login()                 // Authentication
getProfile()            // Get user info
updateProfile()         // Update details
changePassword()        // Password change
getAllUsers()           // Admin list users
updateUserStatus()      // Suspend/activate
```

### Book Class
```php
addBook()               // Add new book
getBook()               // Get details
searchBooks()           // Search with filters
getAllBooks()           // Paginated list
updateBook()            // Edit book
deleteBook()            // Remove book
getBooksByCategory()    // Filter by category
```

### BorrowRecord Class
```php
borrowBook()            // Borrow transaction
returnBook()            // Return book
renewBook()             // Renew borrowing
getUserBorrowedBooks()  // User's books
getOverdueBooks()       // List overdue
getBorrowHistory()      // User history
```

### Fine Class
```php
getUserFines()          // Get user fines
recordPayment()         // Record payment
waiveFine()             // Admin waive fine
getFinesReport()        // Financial report
```

### Reservation Class
```php
reserveBook()           // Make reservation
cancelReservation()     // Cancel
getUserReservations()   // User's reservations
getReservationQueue()   // Queue for book
```

## Configuration Essentials

Edit `config/config.php`:

```php
// Database
DB_HOST, DB_USER, DB_PASS, DB_NAME

// Fine Rates
DAILY_FINE_RATE = 5          // $ per day
DAMAGE_FEE = 50              // % of book value
LOST_BOOK_FEE_PERCENT = 200  // % replacement cost

// Rules
MAX_BORROW_DURATION = 14   // Days
MAX_BOOKS_PER_USER = 5     // Max books to borrow
RESERVATION_HOLD_PERIOD = 7 // Hold days

// Security
SESSION_TIMEOUT = 3600     // 1 hour
PASSWORD_MIN_LENGTH = 8
```
